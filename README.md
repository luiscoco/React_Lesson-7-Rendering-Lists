# React 19.2 - Lesson 7 - Rendering Lists Playground (with Key Strategy Demo)

Interactive mini-app to practice `.map()`, `.filter()`, and compare key strategies (`id`, `index`, `random`).
Includes controls to shuffle and remove items so you can observe reconciliation behavior.

## Demo



## Features and key ideas

- Filter the list by name or profession using `filter()` and memoization.
- Add new people and see how list rendering updates.
- Toggle key strategies to observe reconciliation differences.
- Shuffle or remove items to see how unstable keys can confuse React.

### Example: filtering the list

```jsx
const filteredPeople = useMemo(() => {
  const q = query.trim().toLowerCase();
  if (!q) return people;
  return people.filter(
    (p) =>
      p.name.toLowerCase().includes(q) ||
      p.profession.toLowerCase().includes(q)
  );
}, [people, query]);
```

### Example: key strategies for list items

```jsx
const getKey = (person, index) => {
  switch (keyStrategy) {
    case 'index':
      return index;
    case 'random':
      return Math.random().toString(36).slice(2);
    case 'id':
    default:
      return person.id;
  }
};
```

### Example: add a person with a stable id

```jsx
const nextId = (people.reduce((m, p) => Math.max(m, p.id), -1) ?? -1) + 1;

setPeople((prev) => [
  ...prev,
  { id: nextId, name: trimmedName, profession: trimmedProfession },
]);
```

## File purposes

- `index.html`: Root HTML entry with the `#root` mount point and the Vite entry script.
- `package.json`: Project metadata, scripts, and dependencies.
- `package-lock.json`: Locked dependency tree for consistent installs.
- `vite.config.js`: Vite configuration with the React plugin.
- `src/main.jsx`: React entry point that renders `<App />` into `#root`.
- `src/App.jsx`: Page shell (header, main content, footer) and mounts `FilterableList`.
- `src/index.css`: Global styles and layout.
- `src/components/FilterableList.jsx`: Main UI and state logic (filtering, adding, shuffling, key strategy).
- `src/components/PeopleList.jsx`: Renders the list and applies the selected key strategy.
- `src/data/people.js`: Seed data for the initial list.
- `node_modules/`: Installed dependencies (generated by `npm install`).
- `.git/`: Git metadata for version control.
